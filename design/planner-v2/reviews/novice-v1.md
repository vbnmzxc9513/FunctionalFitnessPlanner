# 新手任務走查 v1

日期：2026-10-19。角色：第一次使用 Fitness Planner、沒有先前排課經驗的使用者。

任務情境：「每週二、四、五打羽球，午休有 40 分鐘，請系統自動產生課表；找到預覽、理解短恢復日，再確認套用。」

## 方法與限制

依照 `research.md` 的角色任務走查方法，實際以 `tools.view_image` 觀看六張 PNG：`02-empty`、`01-week`、`03b-dates-auto`、`08-auto-goals`、`09-auto-body`、`10-plan-preview`。另讀 `prototype.html` 的文字，僅核對畫面文案，沒有操作原型，也沒有修改產品或原型。

這是獨立的模擬使用者／啟發式檢查，不是真實使用者研究。以下「會點」表示從 PNG 推測的下一步，不表示已實際點擊。沒有量測完成率、時間、SUS 或滿意度。鍵盤、讀屏、焦點、捲動後是否能看全內容、資料是否真的保存、返回是否保留草稿，以及套用與衝突保護均為未知。

嚴重度沿用專案定義：P0 可能覆蓋或污染已有紀錄；P1 核心任務受阻／誤認已套用；P2 可完成但需猜測／回頭；P3 文案或視覺一致性。

## 具體問題

### N01 — 自動排整週，預覽卻是另一套三日結果（P1）

- **畫面**：[03b-dates-auto](../png/03b-dates-auto.png)、[08-auto-goals](../png/08-auto-goals.png)、[09-auto-body](../png/09-auto-body.png)、[10-plan-preview](../png/10-plan-preview.png)。
- **可見證據**：自動流程前面是四步，日期為 10/19–10/25，球日為二、四、五；到預覽卻改成三步並出現「加入動作」，日期縮為 10/19–10/23、共 3 天。列表只有一、三、五，摘要也僅說「1 天球日舒緩」。週二、週四沒有列出安排或未排原因。
- **具體誤解與影響**：我無法分辨是系統忽略兩個球日、只挑部分日期，還是切到了手動課表；不能確認這是自己要求的一週計畫。核心任務停在預覽，雖然看得見套用按鈕，也不會安心按下。
- **本輪最小修正**：為這條自動情境提供一致的四步預覽；列出 10/19–10/25 七個日期，含二、四、五球日以及休息日，摘要對應實際天數。若任何日期不排課，在該日期直接寫原因。不要用目前三日畫面作本情境的自動結果。
- **未知**：PNG 無法證明實際生成資料或導頁是否也有此錯誤；本問題首先是設計畫面無法連成可確認的任務流程。

### N02 — 同一日期頁同時顯示 7 天與已選 3 天（P2）

- **畫面**：[03b-dates-auto](../png/03b-dates-auto.png)。
- **可見證據**：開始與結束日期是 10/19/2026、10/25/2026，中間提示「共 7 個日期」；底欄卻寫「已選 3 天」，下行仍是同一週範圍。
- **具體誤解與影響**：新手可能把 3 天當作預先替自己選好的訓練日，也可能認為日期選取沒有成功，回頭尋找另外四天。尚未設定球日與體能可用日，沒有線索能解釋這個 3。
- **本輪最小修正**：底欄改為「期間共 7 天」或「10/19–10/25・共 7 天」。日數必須與畫面日期一致；若要另顯示訓練日數，等下一步有設定後再明確區分。

### N03 — 沒有手選動作，預覽卻宣稱手選 3 個與指定拉伸（P2）

- **畫面**：[09-auto-body](../png/09-auto-body.png)、[10-plan-preview](../png/10-plan-preview.png)。
- **可見證據**：本任務一路使用自動排課，沒有執行手選動作；預覽卻說「先做指定八段動態拉伸」，以及「手選動作 3 / 3 已排入」。
- **具體誤解與影響**：我會以為系統讀到了別人的偏好、殘留先前草稿，或自己漏做某個必填步驟。自動生成的來源變得不可信，也增加返回找設定的負擔。
- **本輪最小修正**：零手選的自動情境不顯示「手選 3 / 3」；若八段拉伸是系統搭配，改成「系統安排：八段動態拉伸」，避免叫作「指定」。若確有預設偏好，必須在前一步明示來源並提供清除方式。
- **未知**：此 PNG 可能代表另一份有手選內容的草稿，但畫面沒有告知此背景，因此不能拿這個背景解釋新手任務。

### N04 — 選填的身體偏好以專業名詞呈現，且已有選取外觀（P2）

- **畫面**：[09-auto-body](../png/09-auto-body.png)。
- **可見證據**：「想加強哪裡？」直接列「前鋸肌、肩胛穩定、臀肌、核心」；僵硬位置直接列「胸椎、髖、肩胸、踝小腿」。前鋸肌、肩胛穩定與胸椎已有淡藍色填色與藍框，沒有名稱旁的解釋，也沒有「系統預選」或勾選文字。
- **具體誤解與影響**：不熟肌肉名稱的新手不確定應選哪個部位，也不確定保持不動是否等同接受了這些偏好。題目雖然選填，仍需猜測或跳過理解。
- **本輪最小修正**：保留專業名稱並補簡短白話，例如「胸椎（上背）」與可辨識的部位說明；選填項目初始不選，或寫明「已選」與預設來源，並給清除操作。以勾選圖示輔助選取狀態。

### N05 — 固定底欄在截圖中遮住檢查內容（P2，互動影響待確認）

- **畫面**：[01-week](../png/01-week.png)、[09-auto-body](../png/09-auto-body.png)、[10-plan-preview](../png/10-plan-preview.png)。
- **可見證據**：週課表的底部導覽列出現在週五與週日之間，週六列無法閱讀；身體感受頁的底欄切在僵硬部位區附近；預覽的「套用到課表」底欄蓋到週五那列的恢復／12 分鐘說明，下方操作文字也只露出一部分。
- **具體誤解與影響**：在要求我檢查並套用時，部分日程資訊看不全。新手可能略過被遮內容，也可能以為列表到此結束。不能僅憑這些截圖判定實際捲動後仍不可達。
- **本輪最小修正**：重出同尺寸截圖時，讓固定底欄保留內容空間，確保最後一列與下方操作能完整出現在可讀區；再用互動原型確認所有內容能捲到欄位上方。若這只是長截圖擷取方式造成，應另補可閱讀的視窗截圖，避免以被遮的圖作驗收證據。

## 本輪判斷

手動／自動入口可辨認，產生預覽與正式套用的界線也有明確文字。短恢復日的理由已能從「球日不硬塞滿 40 分鐘」理解，不需要為了湊滿時長增加訓練。

目前最需要先解決的是自動流程的日期、步驟與結果不一致；修正前，不能宣稱這個新手任務已可可靠完成。以上沒有可從 PNG 確認的 P0，且不代表實際寫入安全已被驗證。

下一輪應以同一份草稿連續操作：空課表 → 七天日期 → 40 分鐘、二四五球日 → 不手選動作 → 七天預覽 → 套用成功狀態；同時檢查返回不丟條件、所有列可捲到完整閱讀，以及實際套用內容與預覽相同。
