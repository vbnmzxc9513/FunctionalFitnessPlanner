# 設計審查與修正摘要

日期：2026-10-19。交付範圍為 PNG、獨立互動原型及實作規格；沒有修改正式產品。

## 方法與結論

以 ISO 9241-11 的有效性／效率／滿意度定義任務，以 Nielsen 準則檢查可理解的操作、狀態、退出與錯誤預防，另以 WCAG 2.2 概念檢查可操作性。來源與後續真人測試設計見 [research.md](../research.md)。本次是四個 agent 的模擬角色／啟發式走查，加上代表性瀏覽器操作，不是真人使用者研究，沒有製造完成率、時間、SUS 或滿意度成績。

**經初審與兩輪複查，已覆蓋的原型核心路徑沒有再重現未解的 P0／P1。仍有三項重要 P2 無障礙細節，應列入正式實作的發布門檻。** 不能把此結論擴大為所有情境通過、正式資料安全已驗證，或已全面符合 WCAG。

## 已改掉的關鍵問題

| 原問題 | 修改後行為 |
| --- | --- |
| 一週問卷最後只看到三天 | 自動範例完整顯示七個日期，肌力／恢復／休息各自列出；手動維持實際選定 N 天。 |
| 看某天像直接進入編輯 | 已安排日為唯讀瀏覽，編輯是獨立入口；草稿詳情標明尚未套用。 |
| 複製／分享／匯入混成不明操作 | 分清「建立分享副本」「預覽來源」「選自己的日期」「最後確認」。 |
| 預設勾選替換原課表（原型 P0） | 預設換日期；已有紀錄不能替換；只有明確選擇後才顯示替換確認與原課表名稱。 |
| 日期欄位改了，確認頁仍顯示舊日期 | 所有確認／完成示例沿用同一份映射，重複、過去、受保護日期均在範例 gate 阻擋並說明。 |
| 保存草稿後重整找不到 | 從專用原型 localStorage key 還原；套用後結束草稿狀態。 |
| 點第二個動作卻改到第一個 | 編輯帶明確日、階段、索引；修改組次／休息／階段、順序、移除都命中指定列。 |
| 草稿預覽、套用成功與可見內容不一致 | 草稿詳情讀草稿；本次工作階段套用後的首頁與日詳情讀剛套用的副本。 |
| 分享後兩天，詳情卻開原第一天、調整仍有三分頁 | 清單、詳情、映射、調整均依實際分享子集；一日與兩日分別實測。 |
| 調整副本只是顯示成功、沒保留 | 修改與新增確實留在原型接收副本；返回原分享確認其內容沒有跟著變。 |
| 不說明是原型，完成畫面像已正式匯入 | 每頁顯示原型告示，確認與完成頁再次說明未實際寫入。 |
| 器材勾選重繪後還原；只分享拉伸仍列三器材 | 器材選擇保留，接收器材摘要依來源子集推導；純舒緩示例為徒手。 |

## 仍保留的三項 P2

1. **鍵盤選取後焦點回到 BODY。** 重繪應保留目前控制的焦點；換頁後應將焦點移到主標題。這與固定操作列遮住焦點是兩件事，後者已在覆蓋頁面修正。
2. **重複按鈕缺少完整可存取名稱。** 「編輯」「加入動作」與週箭頭需補上動作名稱、暖身／訓練／收操及上一週／下一週等脈絡。
3. **短暫操作回饋未設讀屏宣告區域。** 保存、取消與錯誤須有適當 status／alert 與欄位關聯；不能僅靠短暫 toast。

處理要求已併入 [DESIGN.md](../DESIGN.md) 的正式實作驗收。還有少量重複標籤等 P3 文案未全面複評，保留各輪原始記錄，不宣稱全數問題消失。

## 驗證證據與界線

- 主 agent 的 [prototype-checks.json](../prototype-checks.json)：23 狀態 × 320／390／1440px，共 69 組幾何與 handler 檢查，以及四條代表性流程檢查。無橫向溢出或 pageerror。這是自動檢查數，不是使用者成功率。
- 無障礙 agent 獨立檢查同樣三尺寸，並在微調後補 18 組；覆蓋的啟用控制未量到低於專案 44×44 CSS px 目標，Tab 覆蓋頁未再量到固定列遮擋。此尺寸是專案目標，不是將 WCAG AA 的 24px 基準改稱 44px。
- [a11y-v3-measurements.json](a11y-v3-measurements.json)、[最後器材／子集差異](a11y-v3-delta.json)、各角色 v3 報告保留具體操作與限制。
- [render-checks.json](../render-checks.json) 對應 23 張完整手機頁；另交付三張桌面、兩張真實手機首屏、四張流程／架構總覽 PNG，以及 23 頁 PDF。
- 自動排課依條件真正計算、完整動作庫、任意日期、分享後端、正式匯入／撤銷、讀屏實機、軟鍵盤、網路失敗與資料競態都尚未實作或全面測試。

## 下一步

先依設計規格分段接回正式 App，不同時重寫排課引擎與資料模型。補完上述三個 P2，招募不同背景使用者，依 [GOV.UK 任務型測試方法](https://www.gov.uk/service-manual/user-research/using-moderated-usability-testing) 觀察手動、自動、分享及日期匯入；記錄是否需要提示、首次選擇、錯誤恢復、時間與主觀容易度。真人證據不足前，不宣稱「所有人都直覺」。
