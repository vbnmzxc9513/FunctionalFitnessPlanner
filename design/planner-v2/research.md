# 易用性依據與評估方案

研究日期：2026-10-19。這是設計研究與原型，尚未修改正式產品。

## 好用的操作定義

- **有效性**：使用者能完成手動排課、自動排課、分享、指定日期匯入，結果符合意圖；沒有意外覆蓋或誤以為已套用。
- **效率**：從名稱看得懂下一步；分類可快速找到動作；常用操作不用重填；返回不丟草稿。
- **滿意度與掌控感**：知道是草稿、預覽還是正式課表；知道分享了什麼、匯入了哪幾天；能修改、退出與撤銷。

ISO 9241-11:2018 是概念框架，不是提供完成率門檻或指定測試程序。以下數字是本專案設計目標，不能說是 ISO 認證標準。

## 已查閱的一手／權威資料

1. ISO，*ISO 9241-11:2018: Usability: Definitions and concepts*：https://www.iso.org/standard/63500.html 。以指定使用者、目標與使用情境界定有效性、效率與滿意度；本次讀取官方摘要，未聲稱閱讀付費全文。
2. Jakob Nielsen／Nielsen Norman Group，*10 Usability Heuristics for User Interface Design*：https://www.nngroup.com/articles/ten-usability-heuristics/ 。用於狀態可見、符合使用者語言、控制與退出、一致性、錯誤預防、辨識優於記憶、簡潔，以及可復原的錯誤訊息。
3. W3C WAI，WCAG 2.2 *2.5.8 Target Size (Minimum)*：https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum 。AA 基準為 24×24 CSS px，且有間距等例外；本專案自行採較寬裕的主要操作 44×44 px 目標，不能把 44 說成 AA 強制值。
4. GOV.UK Service Manual，*Using moderated usability testing*：https://www.gov.uk/service-manual/user-research/using-moderated-usability-testing 。觀察參與者完成有情境的任務，避免以「你覺得好不好」取代實際操作。
5. GOV.UK Service Manual，*Plan user research for your service*：https://www.gov.uk/service-manual/user-research/plan-user-research-for-your-service 。規劃每輪研究問題與不同背景參與者；官方通常建議每輪 4–8 位，這不是統計代表性保證。

## 本輪評估方式

先由獨立 sub-agent 觀看 PNG，以角色任務走查。每個問題須附畫面、具體誤解、影響、嚴重度與修正。這是模擬使用者／啟發式檢查，不是真實使用者研究；不製造完成率、秒數、SUS 或滿意度成績。

嚴重度使用本專案四級：P0 可能覆蓋或污染已有紀錄；P1 核心任務受阻／誤認已套用；P2 可完成但需猜測／回頭；P3 文案或視覺一致性。

## 後續真實任務測試（另行招募，不在本次假造結果）

| 任務 | 成功判定 | 專案目標 |
| --- | --- | --- |
| 找到兩種排課入口 | 說得出手動與自動差別並選對 | 首次選擇正確；不需主持人提示 |
| 手動排三天 | 找到腿部肌力與胸椎拉伸，放入指定日與階段 | 無遺漏／重複；能自行修改組次 |
| 自動排一週 | 填時間、球日、身體狀態並理解預覽 | 說得出為何某天短課；沒有把預覽當已套用 |
| 分享三天 | 產生只含所選三天的分享副本 | 不包含實做紀錄、健康備註、實際重量 |
| 從連結匯入 | 第 1／2／3 天逐一對應新日期 | 日期對應正確；未確認前不寫入 |
| 遇到日期衝突 | 改日期，或明確替換無紀錄課表 | 已有紀錄零覆蓋；不自動合併增加負荷 |

量測：無提示完成數／總任務數、首次選擇、回頭次數、錯誤與恢復、每項任務時間，以及任務後 1–7 分「這項操作有多容易」的專案單題；不同方法的測量不能混成一個「好用分數」。第一輪以發現問題為主，不用少量樣本宣稱普遍完成率。

原型驗收目標：所有核心任務可由可見文字找到入口；無 P0／P1 未解決問題；320 px 不橫向溢出；主要互動至少 44 px；不用長按或拖曳才能完成核心操作；顏色以外也有文字標示狀態。PNG 不能驗證鍵盤、讀屏、焦點、真實速度、網路失敗或實際寫入安全性，需由互動原型與正式實作補測。
