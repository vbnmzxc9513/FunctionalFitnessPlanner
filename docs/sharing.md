# 分享每日課表

每日課表可下載 PNG 圖片，或複製 `#workout=` 分享連結。支援 Web Share 的瀏覽器另可使用原生分享選單；其他瀏覽器仍能下載或複製。接收者不需登入，也不會將分享內容自動寫入個人課表或 Firebase。

分享內容只保留內建動作庫 ID、階段、組數、次數／時間、每側、休息秒數與低劑量準備組。圖片與公開頁面從內建動作庫重建動作名稱；準備組說明改用一般的徒手／輕阻力提示。

個人資料、UID、日期、週次、打球日、傷勢、健康紀錄、完成紀錄、API 金鑰、AI 分析、課表名稱、私人教練／暖身／收操筆記均不會編入連結或圖片。含自訂動作或未列入內建動作庫的舊版動作時，整份分享會顯示無法分享，避免漏掉動作而誤導接收者。

連結使用版本 1 的 UTF-8 JSON 與 Base64 URL 編碼。讀取端限制 6,000 字元與 8 個不重複動作，拒絕額外欄位、未知 ID、錯誤順序、非法組數與過量準備組。跳躍以雙側落地數計算，上限 24 次；不接受以時間單位規避次數，也不與額外跳繩混用。這是產品的編排限制，並非醫療安全保證。

分享是公開操作，拿到連結的人都能看到動作與劑量。頁面提醒接收者依自身能力、器材與專業建議調整。任何自動套用課表、評估接收者適用性或線上圖片服務都未包含在分享流程中。
