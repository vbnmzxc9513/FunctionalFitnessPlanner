# 分享課表

每日課表可下載 PNG 圖片。單日 `#workout=`、多日 `#program=` 及登入者建立的 `#plan=` 短連結均可讀取；新操作與日期匯入詳見 [排課、收藏與分享](workout-planner.md)。支援 Web Share 的瀏覽器可使用原生分享選單。接收者不需登入就能預覽，必須自己選日期、檢查並確認，才會匯入個人課表。

分享內容只保留內建動作庫 ID、階段、組數、次數／時間、每側、休息秒數與低劑量準備組。圖片與公開頁面從內建動作庫重建動作名稱；準備組說明改用一般的徒手／輕阻力提示。

個人資料、UID、原日期、週次、打球日、傷勢、健康紀錄、完成紀錄、API 金鑰、AI 分析與私人教練／暖身／收操筆記不會編入分享。多日分享可包含使用者確認的公開課表名稱及相對日期間隔。含自訂動作或未知動作時，整份分享會顯示無法分享，不會默默漏項。

內嵌連結使用 UTF-8 JSON 與 Base64 URL 編碼並維持長度上限，太長時明確要求登入建立短連結。歷史 v1 單日資料保留八項上限；新 v3 支援每日 24 個獨立動作、多日最多 28 天，沒有把八項暖身重新包成一項來規避容量。公開短連結在全部日期及處方通過檢查點前不可讀取。編碼、大小與發布完整性見 [v3 資料契約](planner-redesign/data-v3.md)。

讀取端拒絕額外欄位、未知 ID、錯誤順序、非法組數與過量準備組。跳躍以雙側落地數計算，上限 24 次；不接受以時間單位規避次數，也不與額外跳繩混用。這是產品的編排限制，並非醫療安全保證。

分享是公開操作，拿到連結的人都能看到動作與劑量。公開副本不可變更，目前不提供撤回，建立前會明示。匯入為獨立副本，之後雙方修改不連動；已完成或有實做紀錄的目的日期不能覆蓋。頁面提醒接收者依自身能力、器材與專業建議調整，不替收件者判斷適用性。圖片由瀏覽器本機產生。
