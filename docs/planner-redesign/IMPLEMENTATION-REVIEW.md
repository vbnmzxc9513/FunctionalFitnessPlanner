# 排課重新設計：主代理審查與交付

依據：根目錄 [design.md](../../design.md)。本分支由資料、課表內容、介面與設計走查 sub-agent 分工實作；主代理檢查來源、交易與實際畫面，退回不符部分後再驗收。這是程式及 agent 使用性走查，不是五位真人的測試結果。

## 設計一致性

主代理逐張檢視相同日期、資料與視窗尺寸的設計／實際 PNG，包含首頁、選日期、空白日、課表選擇、內容預覽、每日編輯、保存與最後確認。16 組對照見 [capture-report.json](paired/capture-report.json)，畫面寬度為 390／1440；實際操作另驗證 320／390／768／1440。

- [首頁](paired/compare-week-390.png)：藍紫色系、三個主要導覽、手動／自動排課、週日期與已安排數，七個實際日期列含尚未安排。
- [空白日](paired/compare-empty-1440.png)：常見／我的／空白三個起點，只有一個主要操作；桌機日期與編輯內容使用 grid，沒有依固定高度硬推位置。
- [選擇課表](paired/compare-picker-390.png)：常見／我的、搜尋、單列部位、四份起始組合；先預覽內容再加入。
- [每日編輯](paired/compare-day-390.png)：名稱、預估／可用時間與器材、加入課表、八個獨立暖身列與詳情入口；不把八行文字藏於一筆流程資料。
- [確認套用](paired/compare-review-390.png)：日期優先、階段數量與時間、每日期修改、唯一確認套用操作。修改中間一天保留所有其他草稿日期，返回檢查後也保留修改。

唯一核准的結構差異是 P5 沿用原本的保存視窗，以重用既有流程。保存範圍、名稱、目的、位置、資料邊界及固定主操作仍完整，詳見 [產品審查](PRODUCT-REVIEW.md)。P6 的簡短說明文案與範例圖略有不同，仍明示確認後才更新日期，沒有新增操作層級。原型未被改寫來掩蓋產品差異。

## 審查後修正的實際問題

移除空白日競爭主要按鈕、巨大成功提示及確認頁多餘步驟。補可辨識名稱欄、上方時間／器材、與設計一致的切換控制與手機直列入口。重複動作分別顯示新增／更新劑量數，變更階段須先看見。

收藏重用透過既有 `savedWorkoutDay` 還原一般準備組說明；部位篩選由實際動作推導，不依賴只有目的的標籤。分享無效草稿時顯示錯誤並保留草稿。已完成日期的週預覽顯示真正保留的內容，不顯示交易不會採用的建議。

## 資料及維護邊界

四份常見課表與八項暖身共用版本化配方；模板、AI 提示及新 AI 回應驗證共用規則。既有通用讀取驗證仍支援歷史資料。UI 不維護另一套暖身清單或收藏資料庫。

沿用日期與收藏集合，使用集中式容量常數與處方編碼。28×24 私有課表仍一次交易套用；公開副本在全部檢查點完成前不可讀。舊 sequence 的一筆完成／實做不能拆成八筆。詳見 [資料 v3](data-v3.md)。舊週匿名採用仍限原八項格式，新自動排課寫入日期格式；歷史測試使用凍結的舊版本資料，避免用今日產生器偽造舊格式。

## 驗證

- `npm run check`：ESLint、258 個單元測試及正式建置通過。
- Auth／Firestore emulator：66 個測試全數通過，涵蓋權限、保護日期、完整交易、收藏、分享及遷移；包含 28×24 私有／公開來回與新週轉日期 adapter。
- 實際 App：8 暖身＋4 訓練＋2 收操，保存／重開／收藏／快速重用／套用／分享／接收匯入皆保留 14 項、階段與劑量；320／390／1440 通過。
- BYOK 攔截測試：桌機／手機預覽、十項日期處方重開、保留原完成日及其舊暖身、器材、動作庫、身體數據、登出隱私與語言切換通過。未呼叫正式 Gemini。
- 七組自動排課相關 browser suite、登入帳號日期課表、保存錯誤／同名、分享與導覽回歸通過。16 組畫面對照無水平溢出與 runtime error。
- 選配 Functions 共用程式建置與載入通過，沒有啟用付費 AI。browser emulator 入口強制 demo 專案，避免誤用舊測試命名空間。

## 交付與待確認

本分支接續尚未合併的 Android prototype 分支，作為獨立的網頁排課變更審查；未更動 Android 專案或重建 APK。CI 支援 `feat/**` 為基底的分層 PR，避免略過檢查。

尚未發布正式網站。合併後先部署對應 `firestore.rules`，再發布前端；現有 Pages 工作流程不會自動部署規則。五位真人的 10 秒辨識、60 秒加入與 3 分鐘重用任務仍待實際測量，不能宣稱已證明一般使用者一定容易上手。
