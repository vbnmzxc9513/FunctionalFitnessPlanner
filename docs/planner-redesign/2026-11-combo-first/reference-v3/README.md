# v3 設計基準

2026-11-13 封存，依使用者要求避免 context 壓縮後實作偏離方向。

- HTML、八張手機／桌面截圖與原型走查報告為同版快照。
- 原型走查是先前已執行的原型測試，不是正式 React 或真人驗收。
- 涵蓋空白日、加入組合、已有內容、收藏；日期、多日、例外及真實套用尚待補設計。
- 不覆寫此目錄。設計確實需要調整時更新 DESIGN 的理由，再建立下一版基準。
- 實作驗證另存 implementation-review，記錄 commit、資料情境及實際差異。
- 在本目錄執行 `sha256sum -c SHA256SUMS` 可檢查快照完整性；雜湊一致不代表使用體驗合格。
