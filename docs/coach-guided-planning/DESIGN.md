# 教練式自動排課

## 目標
讓新手用少量選擇完成日期排課，回訪者沿用已有條件；在確認前看到自己的條件如何影響實際內容。沿用藍紫色系、日期草稿、規則引擎與資料格式，不新增聊天 API 或第二套排課邏輯。

## 流程
1. 日期：沿用既有 1–28 天選擇。
2. 怎麼練：主要目標、時間快捷選項、可用星期；加強部位、球日／器材／經驗與比賽可展開修改，收起仍可辨識已選內容。文字備註不宣稱被免費規則完整理解。
3. 身體近況：明確詢問本次恢復與活動限制，保留不確定選項；僵硬與痠痛分開，痠痛才追問影響，長文字備註選填。回應恢復選擇的實際含義，不自動抹除治療限制。
4. 確認方向：以已填條件提供短摘要與排課前提醒。自選動作改為選填展開，已有選擇顯示數量且不丟失。直接產生預覽，不要求先手選動作。
5. 預覽：以實際處方計算肌力、協調控制、恢復、休息；顯示目標、時間範圍及偏好落實情況，不把訓練意圖當成已安排。提供直接返回時間／目標或身體狀態的調整入口，重新預覽後才可套用。

## 邊界
- 不因想更像教練而自動提高負荷，保留球日、治療、賽前熟悉度、保護日期、每日時限與八個獨立暖身的既有約束。
- 不自動將過往肩部治療視為已恢復；使用者須更新實際狀態。
- 不捏造身體狀況、訓練完成紀錄、平衡達標或效果保證；明示為免費規則排課。
- 沿用使用者／裝置分區保存，不新增雲端欄位。登入帳號改變仍遵循原資料隔離。
- 每次重排可修改條件；取消或返回不能寫入正式課表，調整不覆寫既有紀錄。

## 驗收
- 390 / 320 / 桌機，中文與英文可完成日期→問答→預覽→修改→重新預覽→套用；無水平溢出。
- 不挑單一動作也能產生有效課表；回訪已選器材、目標與動作保留。
- 無可用日、僅球日、短時段、恢復或治療限制在預覽前可知，不空泛承諾安排肌力。
- 預覽的肌力／協調數與真正處方一致，手選與目標未排入時如實揭露；不依摘要文案猜測結果。
- 改時間／恢復後實際課表改變，仍通過處方、時限及資料保護驗證。

## 排課回饋修正
檢查發現日期排課已讀取 progress，卻沒有把前一週 feedbackValue 傳給既有模板減量規則。本次接通相對於每個實際規劃週的前一週回饋；「太難」會減量，正向回饋不直接自動加重，舊紀錄與保護日期照常保留。
