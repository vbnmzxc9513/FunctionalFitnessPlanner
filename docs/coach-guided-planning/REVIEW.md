# 主代理審查

2026-11-04，依 DESIGN.md 實作並實際操作。這是程式及代理走查，不是新手真人測試，也不宣稱能取代教練的動作觀察。

## 最終行為
- 保留日期→三步問答→預覽→確認套用的單一路徑；器材、球日、目標沿用原使用者／裝置偏好。
- 指定動作與補充目標文字為選填；沒有選動作也可排課。
- 身體狀態回應會以同一個恢復／治療限制判斷優先，不因「精神不錯」清除治療限制。
- 排課前揭露無可用日、只有球日、短時間、恢復與賽前條件；不先承諾必定安排肌力。
- 預覽以實際處方計算肌力、協調控制、恢復、休息，以及目標和活動度覆蓋。缺少處方的歷史訓練不假裝是協調或肌力。
- 「改時間／目標」「調整身體狀態」直接回到相應步驟，保留其他答案；重新預覽並確認前，不寫入日期課表。
- 前一週偏難回饋接入日期排課的既有減量規則，正向回饋不直接升量。
