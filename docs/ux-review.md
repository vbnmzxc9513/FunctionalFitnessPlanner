# 操作流程整合與 review

日期：2026-10-15。設計依據：[操作藍圖](ux-blueprint.md)。

## 交付流程

三個主要入口固定為今天、課表、紀錄。今天聚焦目前動作，週課表保留完整安排及管理，紀錄優先顯示最近實做與翌日回報。帳號／語言／BYOK 在設定。動作庫提供用途、搜尋、常用清單與階段選取；週覆蓋放在週課表內，沒有增加主導覽。

## 主 agent 與領域 review

額外發現並修正：

1. 免登入重新產生保留仍在新課表上的完成標記與私人實做；不清空既有完成事實。
2. 訓練引導的識別包含當日動作、處方、類型與舊版難度；課表變更會重新從未完成動作開始。切換語言與勾選進度不重建實做表單。
3. 手動加入與選取器均使用器材、搭檔、經驗及模板相同的身體限制守門；未知或無法解讀的限制不提供新增訓練，肩部治療只保留有條件的低強度走路。收藏不能繞過排課資格。
4. 匿名預覽在單次更新保存實做與完成；帳號版兩項寫入若後者失敗，明示實做已存、完成需重試。
5. 胸椎活動不以呼吸、力量、跳躍或單純滾筒放鬆充數；同日多動作只算一天。未知自訂動作單列，不按名字猜測。
6. 模板只替換原有低負荷名額，不增加時間或動作數；主肌力、準備組、治療、疲勞與賽前熟悉度原則保留。

## 自動驗證與限制

- `npm run check`：lint、104 項單元測試及正式建置。
- `npm run test:integration`：29 項資料規則／交易測試，以及手機／桌機瀏覽器流程。
- 瀏覽器涵蓋免費零 Gemini、分享隱私、重整、匿名採用、編輯／還原、常用多用途與啟用分離、器材篩選、mock BYOK、身體測量、跨週、語言、實做日期、保存並完成、免登入重排、狀態預覽／套用及翌日回報。
- 選配 AI 後端共用模組 build/import 通過；不啟用付費服務。本次不改 Firestore rules 或建立新集合。

完整動作教學尚未涵蓋全部 83 項；其餘明示只有既有提示。覆蓋顯示安排，不代表完成量、成效、左右平衡或醫療診斷；不要求每天練全身。帳號收藏需匿名或 Google 登入，免登入只供依用途瀏覽。現有課表不會自動被新策略覆寫，須由使用者重新排課。

建置仍有主 bundle 超過 500 kB 的提示（約 520 kB，gzip 約 174 kB）；本輪未擴大到打包架構重整。未驗證正式 Gemini 配額／品質、跨裝置真人使用或長期訓練效果。
