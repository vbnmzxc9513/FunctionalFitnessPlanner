# 以每天的操作為中心

日期：2026-11-16。此需求優先於舊版「組合排課」對整站入口的假設。保留藍色。

問題已在正式程式確認：Training把單日修改導向ManualPlanner，頁頂又要求重新規劃日期；QuickWorkoutPicker部位只列髖／足踝／肩胛，資料中已存在胸卻無入口；頁面把規劃、收藏、分享、恢復評估及統計同時放前面。

本次決策：

1. 今天：日期／簡短進度、動作清單、「新增動作」。收藏、分享、狀態評估放次要入口。不得為修改今天再選日期。
2. 課表：日曆／每天摘要為主，手動新建與自動排課是兩個精簡操作；點日期直接查看或修改。保留新增多日的獨立日期流程。
3. 紀錄：近期實做紀錄在前，翌日反饋、匯出及統計展開才呈現。不刪除資料或功能。
4. 新增／動作庫共用完整部位詞彙與標籤；胸、背、肩、手臂、前鋸肌、核心、臀、髖、大腿前後側、內收肌、小腿、踝足、胸椎等可直接篩選。未分類自訂動作明示未分類，不亂推測身體部位。
5. 當天新增一按就打開單一動作選擇，固定原日期；修改當天一按進該日內容。保留劑量、資格、並行修改、完成紀錄與正式儲存保護，不默默覆蓋已完成內容。

驗收：手機390/320及桌面不橫溢出；「今天→新增」直接看到搜尋／完整部位選單且沒有日期選擇；胸可找到推胸／伏地挺身；內建與自訂動作都有標籤；修改後仍固定原日期且其他日期與既有完成紀錄不變；少字、藍色、主要內容首屏可見。
