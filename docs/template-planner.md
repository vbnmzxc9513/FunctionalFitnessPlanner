# 免金鑰羽球課表

`src/domain/templatePlanner.js` 的 `generateTemplatePlan(exercises, context, dailyTime, lang, options)` 在瀏覽器依固定規則產生課表，不呼叫 AI API、不傳送健康備註給外部模型，也不需要金鑰。回傳結構與 AI 課表相同，最後使用 `validateGeneratedPlan` 驗證。

## 排課規則

- 每週一至五共五個槽位，週末球日也納入負荷。球日午休以輕活動恢復為主。
- 每週最多兩堂主要肌力，至少隔一個非肌力日。疲勞回報、三場球且有連續球日或高球量時，最多一堂。高負荷球局前一天不加主要肌力。
- 固定優先序選擇已啟用的基礎動作；提供肌力、穩定、協調、均衡四種重點，不隨機換動作。自訂動作不納入模板。
- 尊重器材、搭檔、進階動作與肩部限制篩選。獨自預設方向步序不被描述成未知訊號反應。
- 日內依暖身、短協調、主要肌力、輔助、選配收尾排列。第一個主要肌力附同動作的輕準備組。
- 每天最多八項。時間包含左右側、正式組休息、準備組和換動作；不足時先刪低優先工作，再減正式組數，不縮短必要休息。
- 比賽距離以課表每一天的日期計算；最後十天減量、前兩天及比賽日休息、賽後先恢復。賽前訓練僅沿用 `options.previousPlan` 出現過的動作；沒有歷史時只安排恢復。先前課表並不證明已熟悉，使用者仍須確認。

## 回饋與限制

`options.focus`（亦接受 `goalFocus`）為 `balanced`、`strength`、`stability`、`coordination`。`lastWeekFeedback=-1` 或未確認的疲勞備註減少劑量；「太簡單」不會自動加重。自由文字目標不被當成程式指令，也不聲稱已完整解讀；更複雜的需求應由教練確認或使用 AI 方案。

一般健康備註只接受明確「沒有疼痛／沒有受傷」等簡短否定。模板無法理解的非肩部限制、未指明的健康限制或新麻木／無力回報，產生完整休息課表。肩部治療限制不明時僅列低量走路，並明說須由治療端允許，否則休息；不以無痛或日期自動放行。這是保守模板，並不做診斷。

無器材時可安排徒手下肢與可用的上肢動作，不發明拉力器材。不會為了填滿時間加入高強度循環。動作劑量、階段時間與候選 ID 都通過既有驗證器，但這些檢查不構成醫療安全保證。

單元測試包含球日與週末、5–40 分鐘、器材組合、搭檔、停用動作、健康限制、疲勞／負荷與比賽日期矩陣，並檢查固定輸出、輸入不被修改，以及與 AI 課表 schema 的相容性。
