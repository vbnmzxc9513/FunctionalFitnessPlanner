# Fitness Planner 操作藍圖

狀態：2026-10-15，依使用者同意的完整計畫實作。先以本文件固定分工與驗收，再修改畫面。

## 目的與界線

讓羽球愛好者用午休時間知道今天怎麼練、記錄實做並依恢復狀態調整。主要導覽固定為「今天／課表／紀錄」；帳號、語言與 AI 金鑰在設定。維持既有資料格式、課表驗證、完成歷史、實際日期、未知狀態、雙側紀錄與不自動加量原則，不啟用付費 AI。

## 兩條固定流程

1. 首次：條件 → 產生 → 今日摘要 → 開始 → 暖身／準備 → 正式訓練 → 收尾 → 摘要。尚未建立課表時，不顯示可操作的預設課表；既有帳號歷史仍能使用舊預設及舊課表。
2. 日常：狀態 → 預覽需要的變動 → 明確套用 → 訓練 → 保存實做 → 翌日回報。查看其他工作日是週課表功能；日期、暖身與準備組不會因畫面收合而跳過。

## 共用行為

- 每個畫面一個清楚的主要操作。今天聚焦執行，課表聚焦安排，紀錄聚焦回顧。
- 今日引導與完整課表使用同一批 routine IDs；暖身、準備、單側、休息及收操仍可查看。查看下一個動作不等同完成上一個動作。
- 正式組實做保持空白起始；主要區域顯示實做及症狀，阻力／餘力／品質有明確選填與進階說明。保存不推定品質良好。
- 增加可選的「儲存並標記完成」。App 以同一保存意圖處理，失敗時不可聲稱兩者都完成；不得以第二次寫入覆蓋剛存的私人草稿。原有只保存仍可使用。
- 每日狀態的昨天球量先選未確認／沒有／有；未確認維持 null，明確沒有才設 0。有打球才展開分鐘／RPE。
- 無課表差異時只說明「目前沒有調整」及未填欄位；有差異優先顯示動作刪除、組數／次數變化與前後估時。完整前後清單收合。
- 免登入明確標示「本分頁暫存」，登入後才是帳號同步。免費排課使用本機規則；BYOK 才向 Gemini 傳送排課輸入。翻譯不得顯示內部鍵。
- 動作說明用文字步驟／簡短圖解，優先補常排動作的起始姿勢、做法、常見錯誤與簡化版本。不宣稱能診斷傷勢，不引入未驗證影片或新增負荷建議。

## 實作契約與分工

- 主 agent：App 導覽、空狀態、三頁整合、全域文案與驗收腳本；處理保存並完成的資料一致性。
- 訓練引導 agent：Training 與引導元件；新增 `mode='today'|'plan'`、`onViewRecords`。plan 模式保留編輯與全週選日，today 模式聚焦目前動作；依原 routine 記錄完成。
- 表單 agent：ExerciseLog、DailyReadiness、TrainingHistory、coachLocale；onSave(record,{markComplete}) 支援明確保存意圖，不自行 toggle。預覽仍用既有 original/adapted/decision/changed。
- 排課入口 agent：Onboarding、Coach、LoginPrompt、promotionLocale；保持既有受控 props／產生回呼；AI 區收合、健康與經驗可見、修正模式告知與缺字。
- 動作教學 agent：ExerciseLibrary、ExerciseGuide 及獨立的教學資料；教學不改原 catalog／劑量／ID，供 Training 共用。

同一檔案只有一位實作者；跨檔案契約由主 agent 統一，agent 不自行新增導覽或資料 schema。

## 驗收

- 新分頁只有三個主要導覽，沒有未建立就可誤操作的個人課表；產生後能開始今日訓練。
- 首次與日常流程手機／桌機可完成，且每一舊功能都有可找到的新入口。
- 引導不跳暖身／準備／收操，休息日不要求訓練；處方或完成狀態改變後不沿用錯誤的目前步驟。
- 只保存與保存並完成各自正確；更新草稿／既有紀錄／翌日回報不丟失，錯誤可重試，跨帳號及跨週隔離。
- 體能資料與私人說明不進分享；陌生動作有說明；語系切換不清空未存輸入。
- 舊課表、編輯／還原、匿名升級、身體紀錄、BYOK mock、比較建議、課表版本及完成旗標衝突檢查仍通過。
- 完成 lint、單元、模擬器與實際瀏覽器驗證；主 agent review 後才發布，再做首次使用者複驗。

## 使用者追加：常用清單與週平衡

- 動作庫以「全部動作／我的常用」和「暖身／主訓練／收操」兩個明確維度查找；原肌群類別為次要篩選，搜尋保留。
- 同動作可以加入多份常用清單，收藏與允許自動排課分開。既有每動作設定中新增可選 libraryGroups 陣列，不改 ID、處方或舊資料；匿名／Google 帳號保存自己的清單，未登入瀏覽者可先依用途查找。
- 編輯課表先選加入的階段，再搜尋或從常用短卡選動作，取代全部動作的長下拉選單。已停用／刪除動作與重複 ID 排除；動作原有技能階段等限制保留。
- 週課表顯示活動度與肌力／步伐模式各自的覆蓋，採有安排的天數，不把同一天三個髖動作說成三天；呼吸及力量不冒充胸椎拉伸。
- 正常週的既有低負荷槽位依髖、踝、胸椎等用途輪替，控制時間及總量。限制、球量、器材與賽前恢復優先；目的性重複可以保留，較少安排不等於必須加練。
- 平衡提示與人工選擇入口同一份課表；不增加新的主導覽、任意資料夾、總分、補課或自動加量流程。
