# 介面整體改版

2026-10-15。目的：讓使用者在手機上分清楚「看整週」「練今天」「調整計畫」，以一套版型承接既有訓練與資料規則。

## 問題與參考

舊版把週總覽、七日說明、覆蓋表、單日完整訓練與排課條件串成同一頁。相同層級的圓角卡片與操作、13 px 以下說明與重複標題，令主次不清。收合可減少字數，卻仍需逐一猜測內容在哪。

參考官方產品介紹與畫面：

- [Nike Training Club](https://www.nike.com/ntc-app)：以課程與訓練目的為入口，將開始訓練設為明確主要操作。
- [Hevy](https://www.hevyapp.com/features/track-workouts/)：將可重用課表與當次實做分開，記錄時讓每組數字與之前紀錄容易找。保留本 App 不預填實做／不推定完成的資料規則。
- [TrainingPeaks mobile Home](https://www.trainingpeaks.com/learn/articles/trainingpeaks-mobile-home-view/)：先看本週安排、目標與狀態，再深入單次訓練。只借用閱讀層級，不新增 TSS 或恢復診斷。

參考的是操作模式與層級；不複製他人的品牌、插圖、照片或付費功能。

## 頁面與操作

```text
主要導覽：今天｜課表｜紀錄                         設定

今天
  日期 + 今日主題 + 分鐘／動作數 + [開始／繼續]
  今天狀態檢查（短列，可展開；未知仍明示）
  暖身 → 協調 → 肌力 → 收尾的階段導覽
  開始後：目前動作 + 清楚組次 + 完成／實做
  結束後：摘要與紀錄；教練說明／分享為次要操作

課表 → 本週課表（總覽）
  本週方向 + 一行安排摘要 + [調整本週目標]
  七日週曆 + 緊湊的每日角色，點入才看當日詳細
  桌機側欄／手機下方：保存的偏好、週覆蓋、追蹤提示

課表 → 單日內容
  [回到本週總覽] + 選日 + 分階段完整動作
  編輯／還原集中於此，與看整週分開

課表 → 調整計畫
  [回到本週總覽] + 既有條件與目標表單
  進階 AI 次要，保存規則與尚未套用提示保留

首次建立
  1 目標 → 2 球日／時間／器材 → 3 身體限制與建立
  每步只有一個主要前進操作；可返回修改

動作庫
  用途與常用為主篩選，搜尋放在清單上方
  緊湊清單／桌機網格；教學、管理與額外資訊才展開

紀錄
  最近實做與翌日回報優先，統計次要
```

## 視覺系統

- 依使用者偏好恢復原有藍紫色系：淺灰底、白色卡片、sky 藍導覽與 indigo 紫主要操作，使用 Tailwind 原有色票。保留新版型與流程，不覆蓋整組色票或另換品牌色；琥珀表示提醒，紅色表示錯誤。
- 手機標題約 28–32 px，正文 16 px，輔助文字 14 px；日期／標籤才用 12–13 px。
- 以留白、字重與分隔線建立層級，避免每段文字再套一層有色卡片。
- 一個畫面一個主要行動；次要操作用文字或描邊。
- 主要導覽與操作按鈕至少 44 px、明確鍵盤焦點、手機安全區、減少動畫設定；不依顏色單獨表達訓練類型。

## 保留與驗收

課表、實做、處方快照、完成旗標、未知狀態、公開分享白名單及限制守門沿用原邏輯。在相同週／日／動作下，切換總覽／日內容／條件不丟棄已輸入的實做；切換訓練日仍依既有表單作用範圍處理。總覽與日內容不再同時展開；排課表單不再排在單日長清單最底部。

驗證手機／桌機首次建立、免登入、保存與採用、週總覽到日內容、條件未套用、編輯還原、動作庫、每日調整、實做與翌日回報、英文、鍵盤焦點及水平溢出；以實際瀏覽器截圖檢查視覺層級。

## 驗證紀錄

- `npm run check`：ESLint、110 項單元測試與正式建置通過。
- `npm run test:integration`：30 項 Firebase Emulator 整合測試；桌機與手機各自完成一般操作及教練記錄兩組瀏覽器測試。AI 路徑使用模擬回應，沒有呼叫真實 Gemini。
- 新增瀏覽器驗證：首次建立返回仍保留選擇；週總覽與每日內容分開；條件修改未套用提示；手動編輯中點主導覽仍保留編輯畫面；查看下一動作不推定完成，且主項準備組仍先出現在可視範圍。
- 以同一份本機示範課表比較：390 px 手機週頁由 5,058 px 縮短至 1,854 px，1440 px 桌機由 4,330 px 縮短至 1,259 px。這是將日內容與表單移至各自畫面的結果，並非真人操作效率測量。
- 320、390、768、1440 px 四種寬度的週頁皆無整頁水平溢出，並檢查首次建立、今天、訓練中、週總覽、每日內容、條件、動作庫、紀錄及設定截圖。

本版沒有更動排課演算法、Firestore 規則、資料結構、AI 計費或既有實做。真實使用者的上手速度與閱讀感受仍應以後續試用回饋評估。
